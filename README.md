# ❤️ LifeLink

> A modern blood and plasma emergency network prototype that helps hospitals connect with nearby blood donors during critical situations.

🌐 **Live Demo:** https://lifelink-web.netlify.app/

---

## 📖 About

LifeLink is a frontend prototype designed to simplify blood donation during emergencies. It provides an intuitive interface where hospitals and donors can interact, making it easier to search for compatible blood donors during critical situations.

> **Note:** This is a frontend prototype. All donor information shown is sample data for demonstration purposes only. No real donor database or emergency service is connected.
